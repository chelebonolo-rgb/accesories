

## Features

- Home page with header, hero section, about section, feature cards, and footer
- Contact page with a professional enquiry form
- Client-side JavaScript validation for all required fields
- Success confirmation message without page refresh
- Responsive layout for desktop and mobile devices
- Reusable React components: Header, Home, Contact, Footer, and ServiceCard
- Use of React state and effect hooks

## Run locally

1. Install dependencies:
   npm install
2. Start the development server:
   npm start
3. Open http://localhost:3000 in your browser

## Test

npm test -- --watch=false

## Production build

npm run build
